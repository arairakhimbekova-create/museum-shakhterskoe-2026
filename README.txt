ВИРТУАЛЬНЫЙ МУЗЕЙ СЕЛА ШАХТЕРСКОЕ

Загрузка на GitHub Pages:
1. Создайте новый публичный репозиторий на github.com.
2. Нажмите Add file → Upload files.
3. Загрузите СОДЕРЖИМОЕ папки shakhterskoe-museum (index.html, style.css, script.js, data.js и папку assets), а не сам ZIP.
4. Commit changes.
5. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
6. Дождитесь публикации ссылки GitHub Pages.

Исходные фотографии, карта, координаты точек и описания взяты из предоставленного JSON без замены.
